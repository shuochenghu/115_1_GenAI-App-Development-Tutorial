## 方法盤點與授課選擇

本次依新原則先比較兩層：圖片如何傳輸（Base64、URL、Files ID），及任務如何處理（直接Vision、OCR、PDF、辨識後RAG、影像檢索）。方法比較文寫出責任、先備、程式／維護負擔、限制、成本及適用情境；主線直接Base64，不要求學生把全部方法做成作品。

URL與file ID有完整content形狀短例，不執行假網址／placeholder；Files ID另說上傳、重用與清理，與第11週Vector Store不同。OCR與其他平台為後續選擇，不引入額外安裝。PDF直接輸入和File Search索引分開說明，未將單張PNG當File Search支援格式。保留官方連結與未實測界線。

現行官方gpt-5.4-mini支援圖片與結構化輸出，沿用課程模型，不追求更新模型。detail預設auto，只把auto／high／low列為可選；original說明支援與可用情境，不加第四項必測。明確修正「low一定較省」的直覺，以實際usage判讀。

## 時間、學生自主與作業

150分鐘核心含方法15、圖片20、A25、問答20、抽取25、B與App25、除錯與作業20，另留休息10與排障20。A完成Base64→ASCII→data URL→兩項content；驗證／Schema／API完整提供。B選正常及不足兩筆，不要求四種prompt全部付費測。

課後45～60分鐘沿用同App，問答或收據抽取擇一。問答可選截圖／海報／物件，抽取用虛構收據；題目與設計開放，最低要求固定。交Notebook、App、原圖、正常與不足兩份紀錄、README，加一個錯誤／邊界處理與重測、日期或數字與原圖位置查核。評量40／30／20／10為A、B、修正、可重現；不按模式或工具數量加分。

老師問答／抽取各1次，共2次；學生B與作業兩筆可合用，換圖重做另2次，detail選做再1次，額外重跑按實際紀錄。沒有API交功能與預期，模型欄明寫未測，由老師安排共看；不能用手寫輸出補造。

## Notebook格與先備

雙版各26格：15文字、11程式，標題各自起始文字格，僅封面、A與B的教師提醒不同。

| cell ID尾段 | 職責／必要先備 |
|---|---|
| install／colab-key | 預設不安裝、不讀Secrets，不請求 |
| prepare→preview | 匯入與完整圖片驗證；preview只依prepare與本機圖片 |
| a→a-check | A只組content；自測自帶人工bytes，不當真圖片送出 |
| answer | 完整回應檢查與共同規則 |
| qa-run | 先跑prepare、A、answer；不依賴抽取結果 |
| schema | 完整Schema與抽取驗證；執行時需要prepare的json／math匯入 |
| receipt-run | 先跑prepare、A、answer、schema；不依賴前次付費 |
| transport-shapes | URL／file ID形狀，可獨立執行，0請求 |

新語法只解釋本週必要部分：BytesIO、b64encode／decode、data URL、MIME、EXIF、透明白底與SHA；dict／list、with、例外、Schema沿前週。App的**options用來只在抽取時加text參數，不是第二次API；teacher版相同。

## 圖片、狀態與證據邊界

兩張1000×800英文虛構收據與人工manifest由重建腳本建立，非模型成果。清楚圖日期2026-11-11、總額300；缺總額圖仍有品項，但本任務禁止推算，total應為null並列warnings。老闆姓名、電話與地址未提供。課前須實測，不能預設模型一定答對。

本機原圖至多2 MB、每邊2048，單影格；轉正／白底／新PNG後至多4 MB，超限拒絕，不自動縮圖或截斷。預覽與API用同一PNG，原始及傳送SHA分開；metadata去除不等於畫面資料匿名。

App狀態有preview／result／error；新提交、切任務／來源／API模式、清除均清舊結果。圖片或問題驗證、A、缺key均在請求前；回應拒答／未完成／空值、JSON或型別失敗不保存舊答案。表單未提交仍展示最後成功提交，不宣稱是新問題的結果。rerun與下載0新請求。

一般問答文字由人核對；抽取欄位全驗證，有限非負總額不接受bool，未知須原因，有值須可見文字。但模型可能同時抄錯visible_text及值，無法靠自身文字證明；格式合法不等於正確。max_output_tokens=1200可能遇未完成，先縮小任務再評估上限。store=False不保證無處理／無紀錄；本週主線不建Files資源。
