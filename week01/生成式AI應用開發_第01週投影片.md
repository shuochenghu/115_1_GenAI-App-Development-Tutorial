# 生成式AI應用開發

**使用 Python、LLM API、RAG、Agent 與 Streamlit**
**建立可部署的 AI Web App**

第01週｜課程導論與生成式AI應用架構

---

# 這門課要學什麼

- 使用 **LLM API**，而不是只使用聊天網頁
- 用 **Python** 建立 AI 功能模組
- 用 **Streamlit** 建立 Web App 介面
- 串接文件、圖片、資料表與外部工具
- 完成可**公開部署**、可展示的期末專題

---

# 這門課不做什麼

- 不訓練大型語言模型
- 不進行本地端模型微調
- 不要求高階 GPU
- 不把重點放在單純 Prompt 技巧
- 不平均教所有 LLM 平台的語法

> 重點是：**把 AI 能力接進資訊系統**

---

# 和上學期課程的銜接

**上學期「生成式AI理論與實務」已涵蓋**

- 生成式AI基本觀念
- Prompt 與應用場景設計
- Skill 架構
- Claude Desktop 使用 Skill

**本學期延伸**

- 將 Skill 思維融入自己開發的 Web App
- 將 AI 能力接到 Python 程式、資料與工具
- 將作品**部署成任何人都能使用的應用系統**

---

# 聊天工具 vs API 應用開發

| 項目 | ChatGPT / Claude.ai 等網頁版 | LLM API 應用 |
|---|---|---|
| 使用方式 | 人直接對話 | 程式呼叫模型 |
| 輸入資料 | 手動貼上 | 系統自動取得 |
| 輸出處理 | 人閱讀 | 程式解析、儲存、轉換 |
| 整合能力 | 受平台限制 | 可接資料庫、檔案、工具 |
| 適合情境 | 個人助理 | 資訊系統與企業流程 |

---

# 生成式AI應用基本架構

```
使用者
  ↓
Web 介面（Streamlit）
  ↓
Python 應用程式
  ↓
Prompt / Context / Tool Schema
  ↓
LLM API（OpenAI）
  ↓
回覆 / JSON / 工具呼叫 / 串流輸出
  ↓
畫面顯示 / 資料儲存 / 後續動作
```

# 什麼是 RAG？

**RAG = Retrieval-Augmented Generation**
讓模型根據**你的資料**回答問題，而非只依靠訓練知識

```
文件資料
  → 切分段落
  → 建立向量 Embedding
  → 查詢相關段落
  → 將段落放入 Prompt
  → 模型根據資料回答
```

**課程應用範例**
校園課程問答、企業文件知識庫、法規查詢系統

---

# 什麼是 Agent？

Agent 讓模型根據**任務目標**自行決定步驟，並呼叫工具完成多步驟任務

```
目標輸入
  → 思考下一步
  → 選擇工具
  → 執行工具
  → 觀察結果
  → 繼續或完成
```

本課程路徑：**Function Calling（Week 13）→ Agent Loop（Week 14）**

# Skill 在本課程中的角色

本課程**不重教** Claude Desktop Skill 操作

本學期重點是：

- 把 Skill 視為**可重複使用的任務模組**
- 將任務說明、輸入 / 輸出格式、工具規則封裝成 **Python 函式**
- 讓 Streamlit App 或 Agent 呼叫這些模組

**範例模組**
會議紀錄整理、客服回覆草稿、履歷分析、CSV 資料摘要

# 什麼是 MCP？

**MCP（Model Context Protocol）**
讓 AI App 或 Agent 以**標準方式**連接外部工具與資料來源的協定

本課程定位：

- 第15週概念說明與示範
- 不要求全班從零撰寫 MCP Server
- 可作為**期末專題進階加分項目**

- 在自己的 API project 設支出提醒；需達額停用時設定硬性上限（執行可能短暫延遲）

# API 金鑰安全守則

- **不要**把 API key 寫在程式碼中
- **不要**把含有 API key 的檔案上傳到 GitHub
- 使用 `.env` 或 Streamlit secrets 管理金鑰

```python
# ❌ 錯誤做法
client = OpenAI(api_key="sk-abc123...")

# ✅ 正確做法
import os
from dotenv import load_dotenv
load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
```
