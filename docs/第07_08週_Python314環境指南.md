## 新建與選擇環境

先進入week07/week07_streamlit_simple或week08的新版starter／teacher資料夾。
若尚無.venv，使用以下Windows PowerShell指令：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version
python -m pip --version
python -m pip install -r requirements.txt
python -m pip check
```

已有.venv時先保留，新建`.venv-py314`並將以上環境路徑改為該名稱，不直接覆寫。Python安裝升級不會替既有.venv換版本。
VS Code按Ctrl+Shift+P→Python: Select Interpreter，選新環境的Scripts/python.exe。
終端機也要啟用同一環境，或直接以該環境的Python完整路徑執行；不要只看系統python --version。
若啟用腳本受限，可直接執行`.\.venv\Scripts\python.exe -m pip ...`與相同Python的`-m streamlit`，不必改全機執行政策。
macOS／Linux可用python3.14建立環境、source .venv/bin/activate；本次未在這些平台實測。

## 啟動

第7週：`python -m streamlit run student/01_inputs.py`；教師改為teacher，可換其他獨立範例。

## 重現完整套件版本

各requirements固定直接套件；安裝日期不同仍可能解析到不同間接套件。此次完整Windows快照為：
[week07-week08-windows-py314.txt](../environments/week07-week08-windows-py314.txt)。
在上述App資料夾可使用：

```powershell
python -m pip install -r requirements.txt -c ../../environments/week07-week08-windows-py314.txt
python -m pip check
```

只複製App時，另帶完整快照並調整-c路徑；它是Windows／Python3.14驗證組合，不套用到其他平台或Python3.12。
要重現修補版本，須先確認python --version為3.14.0；py -3.14僅選次版本，不保證修補版相同。
不要套用舊的classroom-windows-py312.txt到3.14，也不要把Windows完整快照全套裝入Colab。
