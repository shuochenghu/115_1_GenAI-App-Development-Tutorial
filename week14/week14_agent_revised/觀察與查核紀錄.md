- 沒有重查就寫「沒有重查」，不用刻意重跑。有重查時，寫出第一次缺什麼、第二次字詞怎麼改。
- 被擋下的那一步沒有執行，不算工具次數；寫出擋下原因，以及模型之後怎麼收尾。

## 3 回查一個主張

| 欄位 | 自己的查核 |
|---|---|
| 答案中的一個具體主張 | |
| 引用的source_id、網址與網頁標題 | |
| 紀錄excerpt中對應的短句 | |
| 打開原頁後核對到的條件或位置 | |
| 支持／部分支持／不支持，原因 | |
| 一個版本、數字或網頁日期（沒寫就填「未標示」） | |
| excerpt是否truncated；需要補看哪裡 | |
| 資料不足或讀不到時，還缺什麼證據 | |

不要只寫「有來源所以正確」。讀取時間不是網頁日期，搜尋摘要也不是原文；不足的紀錄可以沒有主張或來源，相關欄位寫「不適用」並說明原因。
