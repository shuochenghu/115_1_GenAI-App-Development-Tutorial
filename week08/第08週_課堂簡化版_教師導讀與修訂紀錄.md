## 完整示範與預期觀察

依 week08_midterm_simple_teacher/README.md 啟動，先不開 API。
離線送出虛構原文：「社團下週舉辦讀書交流，報名方式尚未決定。」應顯示基本檢查通過，沒有摘要結果。
空白與 6001 字元應先停止。啟用並設定 key 後，用同一筆原文示範一次真實 API。
預期 title／summary／key_points 型別正確；不規定唯一標準文字。人工確認沒有補造報名方式或日期。
再指認：form 送出前不提交改值；response 完成才能解析；check_result 只驗型別與非空，不保證內容正確。
結果顯示自己的原文；清除、切換 API 模式或再送出失敗都不可留下舊成功結果。
原範例中的表單改值註解與寬鬆解碼處理不沿用到新版，不藉此宣稱已修正舊版。
