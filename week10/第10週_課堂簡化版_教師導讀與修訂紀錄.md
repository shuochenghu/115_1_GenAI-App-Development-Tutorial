## 時間與練習份量

核心150分鐘：15概念、20資料／向量、20cosine、25A、25真實示範與B、30App、15互看／作業；另休息10與排障20。

A約20分鐘含修正，學生只補計分、dict複製、門檻、降冪排序與top_k；參數／維度檢查完整提供。A檢查含固定排序、來源保留、原資料不變與零向量；通過後原函式直接移入App，不寫第二套。

B用同一小文件做原句、同義改寫、文件外問題，人工指出支持片段或不足；固定一題，只改k或門檻。需比較預期與實際，不能把相似度當正確機率或通用門檻。日期／數字需回查原文。

課後45～60分鐘換合法小文件，沿用同一App，交Notebook、App、文件、兩組搜尋紀錄與README；40／30／20／10為A來源功能、B比較判讀、錯誤修正、可重現反思。題目自由、最低成果固定，不加第二個App、資料庫安裝、RAG回答或部署。

## API與證據界線

- Notebook固定3段＋3問題合批，教師示範有效執行1次；開關預設False。學生App三種新問題各1次，規畫3次；額外重測另計。
- App每次新提交重新向量化文件與問題，減少教學狀態複雜度；正式服務應保存文件向量，新查詢只向量化問題。本例不做跨次快取，不宣稱最省token。
- 改滑桿只用已保存向量重排，rerun、清除與下載0次。A未完成、空／超限輸入或缺key0次；max_retries=0，timeout=60。
- 文件與問題同模型、同維度；依API回傳index還原輸入順序，筆數／維度／有限值／零向量失敗不保存。Embeddings端點不加Responses的store參數。
- 離線只是人工關鍵字規則，不測模型同義理解。離線全零可以是規則不認得用語，不能稱為文件一定無證據；真實高分也可能無答案。
- 未能使用API者先交離線功能及限制，真語意欄明寫未測，由教師另安排共看真實示範並記模式及結果。不要求學生補造品質證據，也不以最高分加分。
- 本週無Responses生成、無file_search、無平台Vector Store。第11週兩種路線共同要求原文支持與資訊不足時不補造。

## Notebook位置與帶課方式

雙版各29格（18文字、11程式），每標題各自起始文字格；僅封面、A答案、B教師提醒不同。原始版另存保留，不能把舊格號直接套用。

| cell ID尾段 | 活動 | 先備與判讀 |
|---|---|---|
| install | 版本與選擇性安裝 | 直接執行0次API；Colab安裝行預設註解 |
| data／small-vector | 片段與人工2維數字 | 各自完整，不依賴學生TODO |
| cosine-fn→cosine-example | 公式方向比較 | 完整函式，預期1／0／0；零向量沒有有效方向 |
| a→a-check | 學生核心 | 先cosine再A；保存hits_result，未完成只提示 |
| demo-fn→offline-run | 人工規則串接 | 需cosine／A／demo；不當真語意證據 |
| real-run | 真實同批向量 | 自帶資料，獨立，預設0次，有效啟用1次；embedding_result失敗為None |
| real-rank | 使用已存向量 | 需cosine／A／real-run；沒有真實結果只提示未測，0次新API |
| b／b-reference | 三類問題紀錄 | 同資料、同模式比較，教師先請學生預判再看排名 |
| app／homework | 同一成果轉移 | 只移入A，狀態與成本由完整流程提供 |

語法盤點：第2週已教sorted／lambda；zip配對、sum的生成式、all／any、isfinite與dict複製，在本版4-1就近解釋。其他list/dict、切片、例外與with沿用前週，不再堆疊語法練習。

2026-11-09 補充參數說明。第 4-1 節可用兩支同方向、不同長度的向量講解 `a` 與 `b`。第 5 節請學生依序指出原文片段、同順序的文件向量、單一問題向量，再讀出 `top_k=2, min_score=0.5` 的意思。先固定問題與門檻，改筆數上限；再固定筆數上限，改門檻。第 7 節分開解讀 SDK 設定與向量請求引數，接著用文件筆數找出第一個問題向量。第 9 節對照滑桿參數與排名函式的參數。

本次驗證涵蓋雙版 Python AST 前後一致、Notebook 離線自測、排名邊界與重建。既有 Streamlit 測試環境匯入失敗，未重跑 AppTest、HTTP 模擬、真實 API 或 Colab。

## App驗收重點

預設文字來自同資料夾sample_data；不依賴使用者電腦的絕對路徑。學生A未完成時按提交先在本機停止；完成A後可離線成功，再切真實模式。

同一表單收文件與問題；新提交先清舊結果，通過才保存。改模式／清除移除舊資料；表單未提交時畫面明示是上次結果。最多6000字元／12段／每段1000字元，問題最多300；超限拒絕，不截斷。start/end對應標準化換行後的貼入文字，非PDF座標。

滑桿不重呼叫API；空結果可下載紀錄但不能冒充有來源答案。下載含模式、模型、問題、原文、參數與hits，不含金鑰或整批向量。資料庫、PDF reader、網頁部署都不作為本週最低要求。
