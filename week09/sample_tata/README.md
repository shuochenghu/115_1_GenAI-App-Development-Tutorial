# 第9週文件讀取範例

- `sample.txt`：UTF-8編碼，三段虛構活動說明，含活動日期、每組4人與總名額32人，供直接讀檔、清理與原文核對。
- `sample.csv`：UTF-8-SIG編碼，含活動、日期、時間、地點、名額5欄及6筆虛構活動；涵蓋讀書交流、Python練習、專題討論、文件處理、成果分享與資料整理。地點`圖書館,討論室`、`創客空間,第二區`以引號包住，示範欄位內的逗號。
- `sample.pdf`：2頁中文文字層，供逐頁抽取與日期、人數核對。
- `sample.docx`：中文段落與表格交錯，供Word本文順序讀取。

內容為虛構教學活動，無真實個資或機密。PDF／Word的活動日期為2026年11月11日，報名截止為11月6日；每組4人、8組、總名額32人。CSV另含11月3日至17日的多筆活動。未提供費用或報名網址。

範例集中保存在本資料夾；執行Notebook前，複製到Notebook目前工作目錄。短例直接開啟`sample.txt`、`sample.csv`、`sample.pdf`及`sample.docx`，程式只寫檔名、不加路徑；Colab直接上傳檔案即可。Streamlit請取消內建TXT範例，透過上傳元件選取檔案。

CSV預期逐列讀出6個字典，每筆5欄；日期與名額也會先讀成字串。CSV已直接提供，教材只讀檔，不需先執行產檔程式。

2026-11-03補充：CSV每筆活動已有完整欄位，可用來討論「一列作為一個檢索單位」；本週App仍以固定字元切塊供觀察，不要求另寫CSV切塊器，也不表示已完成向量搜尋。
