# 第13週｜網路搜尋與Tool Calling實作方法比較（修訂版）

本文沿用原課堂簡化版2026-11-04的官方文件查核，修訂版只調整說明文字與本週做法，沒有重新核對官方文件，授課前請再查一次。
先分清楚兩件事：「搜尋資訊」與「模型提出函式呼叫」可以組合，但不是同一件事。
比較時固定同一個問題：「Streamlit Community Cloud的requirements.txt應放哪裡？」，以及同樣的官方來源與驗收標準；不要求每種方法都做成作品。

| 方法 | 誰負責、會看到什麼 | 額外負擔、費用與限制 | 本課安排 |
|---|---|---|---|
| Responses內建web_search | 平台負責搜尋；回應有web_search_call、sources與url_citation，程式檢查後由人查原文 | 沿用OpenAI；有搜尋工具費及token，可能只讀到摘要，不保證每個網站都能取用 | 本週的網路步驟；只需搜尋時可單獨直接使用 |
| Function Calling＋搜尋服務API | 模型提出結構化參數；程式呼叫自己選的搜尋服務、整理結果再回傳 | 另需服務金鑰、配額與錯誤處理；搜尋與模型分開計價 | 比較與自主延伸，不要求全班申請帳號或做第二套App |
| 指定URL讀取／爬蟲 | 程式只抓已知頁面，自己處理格式、正文抽取與合法存取 | 不等於搜尋引擎；動態頁、登入、網站規則與內容變動都要評估 | 本週不安裝；有明確網址任務時再選 |
| File Search／自行RAG | 從事先提供或建立索引的資料檢索，保留文件來源 | 文件要先準備；不會自動跟著網路更新，也不是搜尋公開網頁 | 回查第9～11週 |
| MCP搜尋工具 | 外部server提供工具與資料，App負責連線與授權 | 要先選服務、確認信任範圍、權限與計價；不會自動取得任意網路權限 | 第15週概念與延伸 |

以上沒有把特定第三方服務列為已驗證可用；選用時請另查該服務的官方文件、資料流向、權限與費用。主線只用一個模型平台與少量Python套件。

## 為何課堂用兩階段，產品卻可以直接搜尋

本週的課綱目標是Function Calling與Skill-like模組，所以完整流程是：
1. 第一次請求只提供`prepare_search`，模型把中文問題改寫成英文`search_query`並提出呼叫。
2. 程式檢查提案（名稱、call_id、欄位、範圍），通過後執行本機A產生搜尋規格。
3. 第二次請求以同一call_id回傳A的結果，再提供web_search搜尋。

修訂版讓模型在第一步負責「改寫關鍵字」，學生看得出模型在函式呼叫中的角色；範圍仍由使用者決定，模型提出不同範圍時程式不執行。
本機函式只準備規格，不假稱它就是搜尋API；模型也沒有執行任何Python。主線強制唯一函式，避免一開始就變成多工具Agent。
只需要網路查詢的產品可以直接提供web_search；Notebook選讀示範這種做法，另外最多1次Responses＋1次搜尋工具，預設關閉。兩種做法的來源檢查與驗收相同，學生只做一個App。

## 網域、引用與資料日期

- 網域篩選用不含`https://`的`allowed_domains`，包含子網域；本週只有Python或Streamlit官方資料。
- sources是搜尋過程查閱的網址，citations是答案實際引用，筆數可能不同；不能把模型寫在答案中的網址直接當成來源。
- 程式確認引用與查閱來源都在指定網域，而且引用頁有被查閱。比對時只看主機與路徑，忽略`#`錨點與`?`參數，以免追蹤參數或同頁錨點造成誤判；標題缺漏時以網址顯示。
- 來源清單不代表已讀完整網頁，也不保證資訊最新；人要打開原文核對結論、版本與發布／更新日期。日期可能未標示，`queried_at_utc`不是發布日期，不能用模型推測補上。

## 成本與生命週期

- 主線每次提交最多2次Responses＋1次搜尋工具。`max_tool_calls`只限制搜尋工具呼叫次數，不限制一次呼叫內的查詢數；搜尋費、token與usage依當時計價核對，不寫固定台幣。
- 沒有上傳Files、建立Vector Store或搜尋服務資源，不需要刪除。本機只保存成功的查核紀錄；`store=False`不代表免傳送、免計費，也不代表取得網站內容授權。
- SDK不自動重試，每次網路等待60秒，不是整個任務的上限；第一階段失敗就不發第二次，第二階段失敗會清掉舊答案。查不到可引用資料時明確記錄，不無限重試。

## 跨週銜接與驗收

- 第11週從指定文件取證，第12週回看原圖，本週回看網頁；三週都強調「格式合格、有來源，不等於主張正確」。
- 第14週再加入多工具選擇、觀察結果與有限次數停止；本週不要求自主規劃或MCP。
- 評量：A與輸入檢查40%、B來源日期30%、錯誤修正20%、可重現10%。正常／不足兩筆可合用課堂與作業，不按路線、工具數量或重複付費加分。

## 官方依據與實測邊界

- [Web search](https://developers.openai.com/api/docs/guides/tools-web-search)：內建搜尋、網域篩選、sources與引用。
- [Function calling](https://developers.openai.com/api/docs/guides/function-calling)：strict函式規格、函式呼叫、function_call_output與reasoning項目回傳。
- [Responses create](https://developers.openai.com/api/reference/resources/responses/methods/create)：max_tool_calls等請求參數。
- [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)：沿用課程模型；帳號權限須另外實測。
- [官方計價](https://developers.openai.com/api/docs/pricing)：依實際模型、工具與usage核對。

官方文件查核與本機SDK檢查，不等於真實帳號已能搜尋。離線模擬、實際搜尋結果、真人瀏覽器與部署證據，分開記錄於教師導讀。
