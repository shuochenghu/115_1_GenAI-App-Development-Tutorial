# 第13週｜網路搜尋與Tool Calling實作方法比較

2026-11-04查核。先區分「搜尋資訊」與「由模型提出函式呼叫」：兩者可組合，但不是同一件事。
共同問題為「Streamlit Community Cloud的requirements.txt應放哪裡？」；比較時固定問題、官方來源與驗收，不要求各方法都做作品。

| 方法 | 責任與可觀察結果 | 負擔、費用與限制 | 本課安排 |
|---|---|---|---|
| Responses內建web_search | 平台搜尋；回應提供web_search_call、sources與url_citation，程式驗證後人查原文 | 沿用OpenAI；有搜尋工具費及token，回應可能只有摘要，不保證所有網站可取用 | 正式網路步驟；單獨直接用可省第一階段 |
| Function Calling＋搜尋服務API | 模型提出結構化參數；程式呼叫選定服務、清理結果並回傳 | 另需服務金鑰、當前支援查核、配額與錯誤處理；搜尋與模型計價分開 | 比較與自主延伸，不新增全班帳號或第二套App |
| 指定URL讀取／爬蟲 | 程式只取已知頁面，自己處理格式、合法存取與正文抽取 | 不等於搜尋引擎；動態頁、登入、robots／網站規則與內容變化需評估 | 不在本週安裝；有明確URL任務再選 |
| File Search／自行RAG | 從提供或索引的資料檢索，保留文件來源 | 文件須先準備；不保證跟著網路更新，也不是搜尋公開網頁 | 回查第9～11週 |
| MCP搜尋工具 | 外部server暴露工具與資料，App處理連線與授權 | 需先選服務、信任範圍、權限與計價；不是自動取得任意網路權限 | 第15週概念與延伸 |

以上不把特定第三方服務列為已驗證可用；選用時另查該服務官方文件、資料流、權限與費用。主線只維持一個模型平台與少量Python依賴。

## 為何課堂用兩階段，而產品可以直接搜尋

本週既有目標為Function Calling與Skill-like模組，所以完整流程先要求模型提出prepare_search，程式驗參數、執行本機A、回傳call_id相符的結果，再做web_search。
這個本機函式只準備規格，不假稱它就是搜尋API；模型也沒有執行Python。主線強制唯一函式，以免一開始就變成多工具Agent。
只需網路查詢的產品可以直接提供web_search；Notebook選讀使用同一任務規格，額外最多1次Responses＋1次工具，預設關閉。兩者資料與驗收相同，學生只做一個App。

## 網域、引用與資料日期

網域篩選使用不含協定的allowed_domains，包含其子網域；本週只選Python或Streamlit官方資料。API的sources是查閱清單，citations是正文引用，筆數可能不同；不能把模型寫出的URL直接當來源。
程式對引用與查閱URL做比對，並驗網域；只忽略同頁fragment，不忽略路徑或查詢參數。來源及標題取自回應，不自行補造。
來源清單不保證全文已下載或資訊最新；人須打開原文核對結論、版本、發布／更新日期。日期可能未標示，queried_at_utc不是發布日期，不能以模型推測補齊。

## 成本與生命週期

主線每次最多2次Responses＋1次內建工具呼叫。max_tool_calls只限制內建工具呼叫，不限制每次內部查詢數；搜尋費、相關token與實際模型usage依當時計價核對，不寫固定台幣。
無Files上傳、Vector Store或搜尋服務資源建立／刪除。本機只保存成功查核紀錄；store=False不是免傳送、免計費或網站內容授權保證。
SDK不自動重試，每次網路等待60秒，並非整個任務上限；第一階段失敗不發第二次，第二階段失敗清舊答案。查無可引用資料明確記錄，不增加無上限重試。

## 跨週與驗收

第11週從指定文件取證，第12週回看原圖，本週回看網頁；都保留「格式／來源存在不等於主張正確」。第14週再加入多工具選擇、觀察與有限次數停止；本週不要求自主規劃或MCP。
評量A與輸入40%、B來源日期30%、錯誤修正20%、可重現10%；正常／不足兩筆可合用課堂與作業，不按路線、工具數或重複付費加分。

## 官方依據與實測邊界

- [Web search](https://developers.openai.com/api/docs/guides/tools-web-search)：內建搜尋、網域篩選、sources與引用。
- [Function calling](https://developers.openai.com/api/docs/guides/function-calling)：strict函式規格、工具提案與function_call_output、reasoning項目回傳。
- [Responses create](https://developers.openai.com/api/reference/resources/responses/methods/create)：max_tool_calls等請求參數。
- [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)：沿用課程模型，文件列有Function Calling與Web search；帳號權限須另實測。
- [官方計價](https://developers.openai.com/api/docs/pricing)：按實際模型、工具與usage查核。
