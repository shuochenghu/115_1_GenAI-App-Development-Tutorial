## 150分鐘與實作份量

15分鐘兩路地圖、25分鐘A、20分鐘問答與失敗檢查、20分鐘自行建置、30分鐘File Search、25分鐘同題B與選一路操作、15分鐘作業／清理，共150；另休息10與排障20。

A約20分鐘含自測，輸入來源片段、回傳context文字及實際sources，不改原hits；超限只在完整區塊間停止，第一段已超限則拒絕，不悄悄截斷。自行建置用A的text生成；File Search用A整理取回證據供人查，不能宣稱控制平台內部context。

B三題：地點、費用、文件外火星氣溫。先填預期原文，再看實際檢索／答案／引用；判讀「取錯／沒取到」與「有證據卻答錯」的差別。有引用仍可能不受原文支持，不以相似度高低或引用數量加分。

課後45～60分鐘，同一App選一路、換合法小文件，交Notebook、App、原文件、三類問答紀錄、README。至少核對一個日期／數字、一個引用、一個錯誤或邊界的處理與重測。File Search另記資源建立／清理結果，不交真實ID紀錄或金鑰；自行建置不要求平台索引。評量40／30／20／10為A、B、錯誤修正、可重現反思，兩路相同。

## Notebook定位與先備

雙版各27格（18文字、9程式），每標題各自起始文字格。僅封面、A答案與B教師提醒不同；教師判讀不是預填模型輸出。

| cell ID尾段 | 活動 | 先備與證據 |
|---|---|---|
| install | 環境與Colab提示 | 預設不安裝、不讀Secrets，不呼叫API |
| a→a-check | context核心練習 | A檢查自帶人工hits；不是實際檢索結果 |
| policy-data | 共同問答規則 | 文件命令視資料、不足固定句、來源要求 |
| answer-fn | 回應檢查 | 完整提供拒答／completed／非空檢查 |
| retrieve-fn | 第10週檢索延續 | 完整同批Embedding、index對齊、cosine與來源 |
| self-run | 自行建置短流程 | 需A、規則、read_answer、retrieve_hits；預設0次，最多2次API |
| fs-evidence | 工具與引用讀取 | 完整提供，檢索序號不冒充字元位置或頁碼 |
| fs-run | 既有索引問答 | 需A、規則、read_answer、fs_evidence及已完成的資源ID；預設0次 |
| b／record | 同題比較 | 相同文件及問題，取回片段、引用與原文逐項核對 |

新語法就近說明：dict(hit)複製來源、join／len含標籤計長度、空區塊與整段邊界；SDK的response.output依type分流、annotations才是檔案引用。其他list/dict、zip／sum、lambda排序與with沿用第2、7、10週，不再堆疊通用框架練習。

## File Search生命週期

resources.py無參數時0次API；--create才建立專用store、上傳同一TXT、附加後最多10次輪詢，全部收到的ID立即保存。索引completed才供App使用；失敗／逾時也保留ID，不自動建立第二份。現有資源未清理時重複create被阻擋。

store設最後活動後1日過期；原始file仍需單獨清理。--cleanup只針對本機紀錄內兩個物件，不列舉帳號；404視已不存在，部分失敗保留待清理ID，可續作。網路逾時未收到ID時，需到平台核對該次操作，不保證完全沒有資源。

App只讀既有紀錄，文件SHA與建立時必須相同；換文件須清理重建。清畫面、關App與store=False不會刪索引或原始file。單次問答API數不包含上傳、索引、輪詢、刪除與儲存費用。

## 基本驗收與成本規畫

兩路預設真實API關閉。自行建置每題1次Embedding＋最多1次Responses；無證據本機回不足，須標示未生成。File Search每題1次Responses＋最多1次工具，設定include取回實際片段；無工具完成事件、來源不符或缺引用的肯定答案不保存。

學生三題自行建置最多6次API；File Search三題3次Responses＋最多3工具，另計資源3次寫入、1～10輪詢及最多2次刪除。老師可先以一題正常與一題不足做兩路示範；同題資料一致，分數不可跨路線直接比較，額外重測另計。

題目／模式／文件SHA與參數存入下載紀錄，便於比對；不存key或向量。新提交、切模式、清除或失敗清舊答案；rerun、展示與下載不再呼叫API。輸入1～3000字元、8段、每段1000，問題300；超限拒絕。

離線只顯示人工挑選前兩段的context，不產生假答案；未測模型品質欄明寫未測，由教師另安排共看。引用、格式或來源ID檢查不能證明語意正確，真實答題仍需原文覆核。
